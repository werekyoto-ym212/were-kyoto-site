# were. document templates

各HTMLの `{{PLACEHOLDER}}` を案件情報へ置き換え、PDFを再生成してください。正式ロゴは `../logo/were-logo-dark.svg` を参照しており、ロゴファイル自体は変更していません。

## PDF生成

Playwrightが利用できる環境で、`documents` フォルダをカレントディレクトリにして実行します。

```sh
node render-pdfs.mjs
```

ブラウザから各HTMLを開き、「印刷」→「PDFとして保存」でも生成できます。用紙はA4、倍率100%、背景グラフィック有効、ヘッダーとフッター無効を推奨します。
